# stm32-keypad-oled
A project derived from a microprocessor lab code with Keypad and 4x4 0.96 OLED display in utilizing more than just the "*" button for backspace.


# Keypad Scan Microcontroller Replay Sequence

Embedded C driver implementation for STM32 interfacing a 4x4 keypad and OLED display.
